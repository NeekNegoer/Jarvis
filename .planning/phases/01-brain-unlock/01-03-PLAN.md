<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/web page → /api/turn, /api/ask, /api/stream | Untrusted cross-origin requests can reach loopback (DNS rebinding) |
| request body text → brain worker | Untrusted-length user input crosses into a spawned claude turn |
| two concurrent turns → shared MCP stdio pipe | Same-session concurrency could corrupt JSON-RPC framing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | DNS rebinding (evil.com → 127.0.0.1) hitting /api/turn | mitigate | `_origin_ok` Origin allow-list on do_POST/do_GET → 403 (SEC-01); verified by test_origin_check_post/get |
| T-01-02 | Tampering | CSRF POST to /api/turn from a malicious page | mitigate | Same Origin check; no cookies used so no ambient auth to abuse |
| T-01-03 | Denial of service | long-string flood to /api/turn | mitigate | `len(text) > 10000` → 400 before spawning the brain thread; verified by test_length_cap |
| T-01-04 | Tampering | two same-session turns corrupt MCP JSON-RPC pipe | mitigate | per-Brain `_lock` wraps the whole think_stream loop (single writer); verified by test_concurrent_turns_serialize |
| T-01-05 | Denial of service | stale job_ids accumulate in _jobs | accept | single-user tool; jobs popped after stream completes; full TTL deferred to Phase 2 per RESEARCH |
| T-01-06 | Info disclosure | session_token treated as a security boundary | accept | localhost-only, no PII; token is a conversation key, not auth — per RESEARCH Security Domain |
</threat_model>
